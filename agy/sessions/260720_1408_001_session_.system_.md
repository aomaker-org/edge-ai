### Root Cause & Fix

#### **Root Cause**
The error occurred because `rclone copy` expects its source parameter to be a **directory**. When given a single file (such as `20260718_logs_core12_1003.zip`), `rclone copy` tries to open the file path as a source directory root, resulting in:
```
ERROR : Local file system at //?/C:/Users/feker/src/irislime/20260718_logs_core12_1003.zip: error reading source root directory: directory not found
```
For single-file transfers, `rclone` requires the **`rclone copyto`** command instead of `rclone copy`.
