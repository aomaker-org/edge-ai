### Step 335 [PLANNER_RESPONSE]
```text
They are blocking on **Windows Standard I/O (stdin/stdout) Pipe Handles**:

### Technical Explanation:
1. **Console Buffer Inheritance**: When commands like `wsl.exe` or `powershell.exe` are launched in the background without explicit file redirection, Windows attaches their output (`stdout`/`stderr`) pipes to an interactive console buffer.
2. **Pipe Wait State (`PIPE_WAIT`)**: Because python and rclone stdout streams remain attached to the parent terminal without flushing or writing to a file, the Windows OS puts the child threads into a **`WAIT_FOR_CONSOLE_INPUT` / `PIPE_WAIT`** suspended state. The process is paused in memory waiting for the console handle to detach.
3. **The Fix**: Redirecting output directly to a log file on disk (`> /tmp/archive.log 2>&1`) detaches the console handles completely, allowing the CPU and network threads to immediately run at 100% speed.
```
