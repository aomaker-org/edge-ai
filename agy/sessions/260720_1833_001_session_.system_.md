### 3. Communication Bridge Methods (Host <-> Phone)

1. **ADB Reverse Port Forwarding (Recommended for Web/Chatbot Bridge)**:
   * **Setup**: `adb reverse tcp:8080 tcp:8080`
   * **Operation**: The Android app hosts an embedded HTTP/RPC service listening on `127.0.0.1:8080`. The host Python driver (`devices/android/common/scripts/adb_chat_cli.py`) sends REST JSON requests and receives response streams.
2. **ADB Shell Native CLI Execution (For NDK Debug & Benchmarking)**:
   * **Setup**: `adb push build/devices/pixel10/pixel10_infer_cli /data/local/tmp/`
   * **Execution**: `adb shell /data/local/tmp/pixel10_infer_cli --prompt "Hello NPU" --backend npu`
