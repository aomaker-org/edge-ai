When an AI agent starts a new session, it must:
1. Read `TODO.md` (append-only human-readable ledger — this is the primary continuity mechanism)

## What the ADR Establishes

### Format Decisions by Data Role

| Role | Format | Why |
|------|--------|-----|
| Machine snapshots / manifests | **JSON** | stdlib `json`, universal tooling, no surprises |
| Human-authored config (watcher rules, scan limits) | **TOML** | comments allowed, `tomllib` in stdlib since Python 3.11 (you have 3.14) |
| Append-only event logs | **JSONL** | one JSON object per line — crash-safe, `grep`/`jq`-friendly, no load-whole-file |
| Flat build metrics | **CSV** | existing `telemetry_builds.csv` — keep it |
| Future cross-env catalog | **SQLite** | queryable, ACID, not git-tracked (derived from JSONL) |
| **JSONC** | **Rejected** | not a standard; `python3 -m json.tool` crashes on `//` comments; VS Code convenience ≠ portable format |
| YAML | **Deferred** | Norway Problem (boolean coercion), no stdlib, `yaml.load()` is an RCE vector |

### The Multi-Environment Problem

The critical insight is: **a single shared manifest file breaks the moment two environments run concurrently** (WSL2 + Docker, or two Codespaces). The solution in the ADR is:

```
logs/manifests/
├── state_wsl2_fekerr-core12.json       ← overwritten each run
├── state_docker_edge-ai-dev.json       ← overwritten each run
├── delta_wsl2_fekerr-core12_260720_1419_001.json   ← immutable per-run
└── ...
logs/scan_events/
├── wsl2_fekerr-core12.jsonl            ← append-only forever
└── ...
```

Every file carries a **host identity envelope** (`env_type`, `hostname`, `git_commit`, `project_root`), so files from different environments are naturally namespaced and never conflict.

### The Delta Gap (what's missing)

The existing `generate_irislime_manifest.py` and `generate_build_manifest.py` are **full-rescan, no memory of the previous run**. The ADR documents the load-compare-emit-save cycle needed to enable "what changed since last scan?" — which becomes `make scan` in the planned target table. See [docs/MANIFEST_AND_SCAN_ARCHITECTURE.md](file:///home/fekerr/src/edge-ai/docs/MANIFEST_AND_SCAN_ARCHITECTURE.md) for the full pseudocode.
