## 🏛️ 1. Core Architecture & GitHub Facilities

To maintain **zero hosting costs**, **maximum reliability**, and **seamless repository integration**, the `edge-ai` dashboard relies primarily on native GitHub facilities:

```text
┌───────────────────────────────────────────────────────────────────────┐
│                    GitHub Pages (dash.aomaker.org)                    │
│   (React / Single-Page Application using Vanilla CSS & Modern Fonts)   │
└───────────────────────────────────┬───────────────────────────────────┘
                                    │
       ┌────────────────────────────┼────────────────────────────┐
       ▼                            ▼                            ▼
┌──────────────┐          ┌──────────────────┐          ┌──────────────────┐
│ GitHub API   │          │ GitHub Actions   │          │ MQTT WebSockets  │
│ (Octokit)    │          │ (CI/CD Pipelines)│          │ (OCI Free Tier)  │
│ - Releases   │          │ - Runs telemetry │          │ - Real-time SLM  │
│ - Matrix Status         │ - Builds Pages   │          │   inference data │
│ - Issue/Proj │          │ - Deploys site   │          │ - Temp / HW logs │
└──────────────┘          └──────────────────┘          └──────────────────┘
```

### 1.1 GitHub Pages (Static Hosting & CDN Edge)
- **Host**: Free SSL-enabled static deployment served directly from GitHub's global CDN.
- **Custom Domain**: Mapped to `dash.aomaker.org` or `aomaker.org/dashboard` via CNAME records and DNS A-records.
- **Framework**: Lightweight React / Vite or Vanilla HTML5/ES6 SPA with rich dark mode UI, zero heavy server dependencies.

### 1.2 GitHub Actions (Automated Telemetry Pipeline)
- **Triggers**: Scheduled cron jobs (`*/15 * * * *`), push events to `main`, and manual dispatch.
- **Jobs**:
  1. Executes `make agy-sync` to parse AI session logs.
  2. Executes `make ai-log-diff-demo` to generate semantic log diffs.
  3. Formats summary JSON telemetry files (`build/telemetry_summary.json`).
  4. Deploys updated dashboard state to the `gh-pages` branch automatically.

### 1.3 GitHub API Integration (Octokit / REST / GraphQL)
The dashboard UI consumes the GitHub REST & GraphQL APIs dynamically without needing a backend server:
- **Repository Health**: Displays active branches, recent commits, and pull requests.
- **Build Matrix Verification**: Fetches status badges for hardware backends (Intel SYCL, Vulkan, OpenVINO, LiteRT).
- **Release Tracking**: Lists downloadable model quantization weights and compiled binary releases.
- **Discussions & Projects**: Embedded GitHub Discussions feed for community maker interactions under `aomaker.org`.

## 📊 2. Dashboard UI Modules & Feature Layout

1. **Header & Portal Navigation**:
   - Quick links to `aomaker.org` (Maker Hub), `jason-lab.dev` (Acme Lab engineering logs), and `edge-ai` GitHub Repository.
2. **Real-Time System Metrics Panel**:
   - Hardware compilation matrix status.
   - SLM inference performance gauges (tokens/sec, memory bandwidth, TTFT - time to first token).
3. **AGY Telemetry & AI Session Monitor**:
   - Live counter of captured AI prompts, responses, and session records in `agy/`.
4. **AI Log Diff Surface Visualizer**:
   - Interactive log diff UI displaying semantic delta reports generated by `ai-log-diff/tools/semantic_log_differ.py`.
