# AI Log Diffing Subproject (`ai-log-diff`)

Welcome to the **`ai-log-diff`** subproject, an intelligent log comparison and anomaly surface detection framework designed specifically for build, test, and debug telemetry artifacts in `edge-ai`.

---

## 🎯 Vision & Core Problem

Traditional line-by-line diffing tools (`diff -u`, `git diff`) fail when applied to software build and test logs. Modern build/test logs contain:

- **Timestamp & Thread Noise**: Every line differs due to volatile timestamps (`2026-07-20 08:12:00.123`) and thread ID shuffling.
- **Memory Address Drift**: Dynamic pointer addresses (`0x7fff5fbff000`) fluctuate across execution runs.
- **Repetitive Verbosity**: Thousands of progress indicators mask the single critical line where an error cascade originated.

**`ai-log-diff`** replaces naive text diffing with **AI-Assisted Semantic Log Event Diffing**:
1. **Normalizes** volatile tokens (timestamps, PIDs, memory addresses, transient paths).
2. **Extracts** structured log event templates (powered by Drain/LogPai log parsing algorithms).
3. **Isolates** structural delta surfaces (new errors, missing success steps, status regressions).
4. **Synthesizes** LLM-ready contextual prompts for automated Root Cause Analysis (RCA).

## 🚀 Quick Usage Example

Compare two build or test logs to extract normalized semantic diffs and generate an AI analysis context:

```bash
python3 ai-log-diff/tools/semantic_log_differ.py \
  --log-a ai-log-diff/examples/build_pass_001.log \
  --log-b ai-log-diff/examples/build_fail_001.log \
  --md-out build/log_diff_report.md
```
